# Discrete_Mathematics
Binary Relations Lab - Vercel deployment

Files:
- index.html: complete website (HTML, CSS, JavaScript in one file)

Run locally:
1. Open index.html in your browser, or
2. In VS Code, use the Live Server extension.

Deploy to Vercel:
1. Create a new GitHub repository.
2. Upload index.html to the repository root.
3. In Vercel, choose Add New -> Project and import that repository.
4. Framework Preset: Other.
5. Build Command: leave blank.
6. Output Directory: leave blank or use the project root if prompted.
7. Deploy.

No Node.js, npm packages, API, or backend are required. The site is fully client-side.

Features:
- Custom student/course input
- Report Case 1 and Case 2
- Ordered pair generation
- Reflexive, symmetric, and transitive checks
- Equivalence relation detection and equivalence classes
